# DFArchon

Digital Frontier Archon.

DFArchon is a community exploring onchain reality through Dark Forest, fully onchain games, privacy-first systems, and self-sovereign digital worlds.

We build where the map is hidden, the rules are verifiable, and the universe has no off-switch.

## Signal

- Dark Forest community rounds, plugins, and game infrastructure
- ZK fog of war, private execution, and privacy-native experiments
- MUD, Noir, Aztec, Solidity, React, and TypeScript
- Onchain culture, autonomous worlds, and player-owned frontiers

## Run Locally

```bash
pnpm install
pnpm run dev
```

The site runs at `http://localhost:5173`.

## Commands

```bash
pnpm run build
pnpm run typecheck
pnpm run lint
```

No kings. No reset button. Just worlds that keep running.
